| 野花 | https://raw.githubusercontent.com/morenb3396/lx-music-sources/main/sources/yehua.js |
| 长青 SVIP v1.3.0 | https://raw.githubusercontent.com/morenb3396/lx-music-sources/main/sources/changqing-v1.3.js |

每次导入一个音源，同时只能启用一个。
